# NeonNet
A pretend GTA-style city web: Lowside Customs (car mods), Velvet Motorworks (super cars), SkyHaul Aviation (planes/helis), Ironclad Surplus (armored vehicles). All money is fake. Original art and names, fan-made, not affiliated with any game company.

Static site: index.html + app.js. Hosted on Cloudflare Pages.
